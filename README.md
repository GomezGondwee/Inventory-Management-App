# Inventory Manager

A modern Android application for managing inventory, tracking stock, and handling sales.

## Features
- **Stock Management**: Track and manage inventory items.
- **Sales Tracking**: Monitor sales and calculate totals.
- **Empties Management**: Keep track of empty containers or returns.
- **Modern UI**: Built with Jetpack Compose and Material 3.

## Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Design System**: Material Design 3
- **Navigation**: Navigation Compose
- **Image Loading**: Coil
- **Architecture**: Clean architecture approach with separation of concerns.

## Project Structure
- `app/src/main/java/com/example/inventorymanager/`
    - `ui/`: Compose themes and screens.
    - `data/`: Data models for Inventory, Sales, Stock, and Empties.
    - `logic/`: Business logic and processing.
    - `MainActivity.kt`: The main entry point of the application.

## Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on an emulator or physical device.
